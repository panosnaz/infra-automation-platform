## Documentation

This folder is reserved for **generated and customer-facing documentation** — for example, a future rendered documentation site (MkDocs or similar), API references, or user-facing guides.

**Internal engineering knowledge — architecture, ADRs, runbooks, and AI notes — lives in [`knowledge/`](../knowledge/README.md).** That folder is the authoritative source for anything an engineer, an AI agent, or a future semantic-retrieval pipeline needs to understand how this platform is designed and why.

If you're looking for the Platform v2 Reference Architecture, ADRs, or operational runbooks, start at [`knowledge/README.md`](../knowledge/README.md).
